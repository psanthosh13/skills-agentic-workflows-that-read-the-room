## Recent updates worth watching

- **Copilot code review from your own tools:** You can now request a Copilot review through the REST and GraphQL APIs and optionally set the review effort level. The Default effort level is now Balanced. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level).
- **Dynamic workflows in Copilot CLI:** A dynamic workflow is a program that mixes automated steps with agents, with the steps defined in code so they run the same way every time. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app).
- **Actions retention covers more:** Retention settings now apply to checks, workflow runs, and statuses, not only artifacts and logs. Changing the setting won't restore data already removed. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-actions-retention-now-covers-checks-runs-and-statuses).
- **Copilot app for beginners:** A beginner series covers [running several agents at once](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-run-several-agents-at-once/) and [using the diff, terminal, and browser](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-using-the-diff-terminal-and-browser/). Source: [GitHub Blog](https://github.blog/latest/).
- **Agentic workflow examples:** Browse sample workflows such as `daily-issues-report` and `weekly-comment-sync` for ideas. Source: [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/).
